# YMM4 クレジット自動出力プラグイン

ゆっくりMovieMaker4(YMM4)で作った動画の「使用素材クレジット」を、プロジェクト(ymmp)から自動で組み立てて `クレジット.txt` に書き出すプラグインです。

素材ごとに出典とクレジット文を一度登録しておけば、以降の動画では登録済みの素材を見つけてクレジットを並べてくれます。動画の概要欄に貼るクレジットを毎回手で書く手間を減らせます。

## できること

- 現在開いているプロジェクト、または選んだ ymmp から、使っている素材を抽出して登録する
- 素材ごとに「素材名 / 出典 / クレジット / 種類」を編集する(複数行をまとめて編集もできる)
- 同じ出典の素材を「まとめる」と、何個使っていてもクレジットを 1 行にまとめて出す
- ymmp と同じフォルダに `クレジット.txt` を出力する。登録していない素材やクレジットが空の素材は「クレジット該当なし」として末尾に並ぶので、書き漏れに気づける

対象になる素材は次のとおりです。

| 種類 | 見分け方 |
| --- | --- |
| 立ち絵 | キャラ素材のフォルダ |
| BGM / 効果音 / 画像 / 動画 / その他 | ファイルのパス |
| 音声(合成音声) | 音声エンジンと声の種類 |
| フォント | フォント名 |

## 動作環境

- Windows
- ゆっくりMovieMaker4(.NET 10 版)。動作確認は v4.57.0.1 で行っています

## インストール

1. [Releases](https://github.com/game-obera/ymm4-credit-plugin/releases) から最新の `YMM4CreditPlugin-v<バージョン>.ymme` をダウンロードする
2. YMM4 を終了してから、`.ymme` ファイルをダブルクリックしてインストールする
   - ダブルクリックしてもインストーラーが開かないときは、YMM4 のヘルプメニューから拡張子の関連付けを行ってください
   - 手動で入れる場合は、`.zip` を展開してできた `YMM4CreditPlugin` フォルダを、YMM4 のフォルダ内の `user\plugin\` に置きます
3. YMM4 を起動し、メニューの「ツール」→「クレジット自動出力」を開く

## 使い方

### 1. 素材を登録する

1. 「現在のプロジェクトから抽出」または「ymmp から抽出」を押す
2. 出てきた一覧で、登録したい素材にチェックを入れて「追加」を押す(登録済みの素材は出てきません)
3. 「登録済み素材」の表で、出典とクレジットを入力する
   - 音声ファイルは BGM か効果音か判別できないため、種類は「その他」で登録されます。必要に応じて直してください
   - 複数行を選んで「選択行に適用」を押すと、出典・クレジット・種類をまとめて書き込めます

### 2. 出典ごとの設定(必要なら)

「出典一覧」には、素材に入力した出典が自動で並びます。

| 項目 | 意味 |
| --- | --- |
| まとめる | オンにすると、その出典の素材が何個使われていても「まとめ用クレジット」を 1 行だけ出す |
| 出力先 | まとめ行を出す見出しの種類。未指定なら、使われた種類のうち出力順で先頭のもの |
| 掲載不要 | オンにすると、その出典の素材はクレジットに出さない |

### 3. クレジットを出力する

「現在のプロジェクトから出力」または「ymmp を選んで出力」を押すと、ymmp と同じフォルダに `クレジット.txt` ができます(既にあれば上書きします)。

- 現在のプロジェクトに未保存の変更があるときは、出力・抽出の前に保存を求めます(古い内容から出力しないため)
- 素材はファイルの絶対パスで照合します。素材ファイルを移動・改名すると別の素材として扱われるので、登録し直してください

## 登録データについて

登録した内容は、プラグインのフォルダ(`YMM4 のフォルダ\user\plugin\YMM4CreditPlugin\`)の `credit-data.json` に保存されます。

- プラグインを更新する前に、念のため `credit-data.json` をバックアップしておくことをおすすめします
- 別の PC に移すときは、このファイルをコピーしてください(素材のパスが同じ場合のみ照合できます)

## ソースからビルドする

必要なもの: .NET 10 SDK、YMM4 本体

1. 環境変数 `YMM4_PATH` に YMM4 のフォルダを設定する(例: `C:\YukkuriMovieMaker_v4`)
2. テストを実行する
   ```
   dotnet test tests/YMM4CreditPlugin.Core.Tests
   ```
3. Release でビルドすると、`%YMM4_PATH%\user\plugin\YMM4CreditPlugin\` に DLL が配置されます
   ```
   dotnet build src/YMM4CreditPlugin -c Release
   ```
   配置せずにビルドだけしたいとき(YMM4 の起動中など)は `-p:SkipPluginDeploy=true` を付けます。

構成:

| フォルダ | 内容 |
| --- | --- |
| `src/YMM4CreditPlugin.Core` | ymmp の解析とクレジットの組み立て(YMM4 に依存しない) |
| `src/YMM4CreditPlugin` | YMM4 のプラグイン本体(画面) |
| `tests/YMM4CreditPlugin.Core.Tests` | Core のテスト |
| `scripts/release.ps1` | 配布用パッケージの作成とリリース |
