# YMM4 クレジット自動出力プラグイン 設計

## 目的・背景

YMM4(ゆっくりMovieMaker4)で作った動画の概要欄に貼る「使用素材クレジット」を、毎回手で書かずに済むようにする。

- 素材(立ち絵・BGM・効果音・画像・動画・合成音声・フォント)ごとに、出典とクレジット文を一度登録すれば、以降の動画では ymmp から機械的にクレジット文が組み上がる。
- 登録・編集は YMM4 の中の GUI で行う。

先行事例として作者の個人用スクリプトがある(フォルダ単位のルールで出力)。**本プラグインはこれとは独立**で、互換も移行も不要(ユーザー決定)。ymmp の読み方の参考にはしてよい。

## ゴール

1. YMM4 のメニューに「クレジット自動出力」項目があり、押すとウィンドウが開く。
2. 現在のプロジェクト、またはファイル選択した ymmp から使用素材を抽出し、選んだものを素材リストに登録できる。
3. 素材リストで、素材ごとに **素材名 / 出典 / クレジット / 素材種類** を編集できる。
4. 現在のプロジェクト、または選択した ymmp について、ymmp と同じフォルダに `クレジット.txt` を出力できる。
5. 同じ出典の素材を、出典ごとの設定で「1 行にまとめる / 素材ごとに出す」を切り替えられる。

## 非ゴール

- 個人用スクリプトとその登録データとの互換・取り込み。
- フォルダ単位のルール(フォルダ配下を自動でクレジット付与)。登録は**ファイル単位**(ユーザー決定)。
- パスの正規化・付け替え(相対パス化、フォルダ移動への追従)。照合は絶対パスのみ(ユーザー決定)。
- 除外フォルダ設定(ユーザー決定で不要。代わりに抽出時のチェックボックス選択で対応)。
- YMM4 の動画出力時の素材一覧(`○○ - 素材一覧.csv` / 内部の `TimelineResource`)の流用。ファイル名しか持たず、別フォルダの同名ファイルを区別できないため、ymmp を直接読む。
- 未保存のプロジェクトの自動保存。

## アンチゴール(動いても失敗とみなすもの)

- 登録済みの素材が、出力時に黙ってクレジットから漏れる。漏れる可能性のある素材は必ず「クレジット該当なし」区画に出す。
- ユーザーが書いたクレジット文を勝手に書き換える・失う(保存データの破損、別素材の上書き)。
- 未保存の変更を無視して古い ymmp から出力し、それに気づけない。

## 制約

- 言語・基盤:C# / WPF、.NET 10(YMM4 本体が net10.0 / WindowsDesktop)。
- YMM4 の参照 DLL は環境変数 `YMM4_PATH`(例 `C:\YukkuriMovieMaker_v4`)から参照する。パスを決め打ちしない(作者の別プラグインのビルドと同じ流儀)。
- コードコメント・ログメッセージは日本語。
- ソースは新規リポジトリ `ymm4-credit-plugin`。ビルドした DLL は YMM4 の `user\plugin\<プラグイン名>\` に置く。

## 調査で分かっている事実

- **メニュー**:公式の `YukkuriMovieMaker.Plugin.IToolPlugin`(`ViewModelType` / `ViewType` / `Name`)で「ツール」メニューに項目が追加され、ウィンドウが開く。作者の別プラグインが同じ方式。
- **現在のプロジェクト**:公式 API なし。作者の別プラグインはリフレクションで `Application.Current.MainWindow` → `MainViewModel` → `ProjectFilePath` 等を辿って取得している。未保存状態(`hasUnsavedChanges` 相当)も取得している模様。本プラグインも同様に、**保存先パスと未保存かどうかだけ**をリフレクションで取得し、中身は保存済み ymmp を読む。
- **ymmp**:UTF-8(BOM 付き)の JSON。
  - ルートの `FilePath` は ymmp 自身のパス(素材ではないので除外)。
  - `Timelines[].Items[]` 配下の `FilePath` が動画・音声・画像の素材(`$type` が `...Items.VideoItem` / `AudioItem` / `ImageItem` など)。
  - 立ち絵はキャラの `Directory`(例 `C:\chara\キャラA`)。
  - 合成音声はキャラの `Voice` の `API` / `Arg`(例 `EngineA` / `f1`)。VoiceItem の `CharacterName` でキャラ名が分かる。
  - フォントは `Font`(例 `フォントA`)。テキスト・字幕・ボイスアイテムに付く。
- **YMM4 の素材一覧の表記**:声質は `EngineA / 声1`、立ち絵はキャラ素材フォルダ名、動画・音声・画像は拡張子なしのファイル名。

## 決まっている仕様

### ウィンドウ構成(上から)

1. **クレジット出力**:「現在のプロジェクトから出力」「ymmp を選んで出力」
2. **抽出**:「現在のプロジェクトから抽出」「ymmp から抽出」
3. **素材リスト**:登録済み素材の一覧(編集可能)
4. **出典一覧**:出典ごとのまとめ設定

「ymmp を選んで…」は Windows 標準のファイル選択ダイアログ(`*.ymmp`)。

### 素材リスト

- 1 行 = 素材 1 つ。列は **素材名 / 出典 / クレジット / 素材種類**。
- 素材種類:立ち絵 / BGM / 効果音 / 画像 / 動画 / 音声(合成音声) / フォント / その他。この順で出力する。
- 照合キー(素材の同一性)
  - ファイル素材:**絶対パス**(大文字小文字は区別しない)。ファイルを移動したら別素材扱い。
  - 別 PC・YMM4 や素材フォルダの移動でパスが変わった場合の付け替え機能は作らない。壊れたら再登録(ユーザー決定:自己責任でよい)。
  - 立ち絵:キャラ素材フォルダのパス。
  - 合成音声:音声エンジン + 声の種類(`API` + `Arg`)。
  - フォント:フォント名。
- 素材名の初期値:ファイルは拡張子なしのファイル名、立ち絵はフォルダ名、音声は YMM4 の表記に近いもの(取れなければ `API / Arg`)、フォントはフォント名。ユーザーが自由に書き換えられる。
- 複数行を選んで、出典・クレジット・素材種類を一括で書き込める。
- 行の削除ができる。

### 抽出

- 対象の ymmp から素材を集め、**チェックボックス付きの選択画面**を出す。チェックした素材だけ素材リストに追加する。
- すでに素材リストにある素材は追加しない(選択画面に出さない、または未チェック・登録済み表示)。
- 抽出時の素材種類の初期推定:立ち絵・音声・フォントは確定。音声ファイル(BGM か効果音か)は判別できないので初期値は「その他」などでよく、ユーザーが直す前提。

### クレジット出力

- 出力先:対象 ymmp と同じフォルダの `クレジット.txt`(既存なら上書き)。
- 対象 ymmp の使用素材を素材リストと照合し、素材種類ごとに見出しを付けて並べる。空の種類は見出しごと省く。
- 出典ごとのまとめ設定
  - 「まとめる」オン:その出典の素材が何個使われていても、出典に設定した**まとめ用クレジット文**を 1 行だけ出す(種類をまたいでも 1 行。出す見出しは出典ごとの「出力先」で選ぶ)。
  - オフ:素材ごとのクレジット文をそれぞれ出す。
  - 同じ文面が重なったら 1 行にする。
- 「クレジット該当なし」区画:クレジット文の後に別区画として出す。対象は、(a)素材リストに無い素材、(b)リストにあるがクレジット(まとめ時は出典のまとめ文)が空の素材。種類と素材(パス/名前)を並べる。
- 自分の録画など登録しない素材が毎回「該当なし」に並ぶのは許容(ユーザー確認済み)。

出力イメージ:

```
■立ち絵
…
■BGM
出典名 https://example.com/
■効果音
効果音：出典1 https://example.com/

# --- クレジット該当なし ---
# [動画] C:\a\rec.mp4
# [フォント] フォントA
```

### 現在のプロジェクトの扱い

- プロジェクトが一度も保存されていない(パスなし)場合:メッセージを出して中止。
- 未保存の変更がある場合:「保存してから実行してください」と警告して中止。自動保存はしない。

## Claude の判断で決めたもの(ユーザー未確認)

- 出典一覧は素材リストに入力された出典名から自動で作り、出典ごとに「まとめる」とまとめ用文面を持たせる。まとめ用文面を出典側に持つのは、同じ出典の各素材の文面を揃える手間をなくすため。
- 出力の見出し書式(`■種類`)、該当なし区画の `#` 書式、素材種類の並び順。
- 未保存時は警告して止める(自動保存しない)。
- 「まとめる」出典の素材が複数の種類にまたがる場合も、まとめ文は**1 行だけ**出す(立ち絵の画像を画像として使った場合などに二重に載らないように)。出す見出しは出典の「出力先」の種類で、未指定なら使われた種類のうち出力順で先頭のもの。同じ文面の重複除去は**同じ種類の見出しの中だけ**で行う。
- 使用素材の範囲:`Timelines[].Items[]` 配下にあるもの(全シーン。非表示・無効のアイテムも含める。安全側に倒し、漏れより載せすぎを選ぶ)。キャラ一覧にあってもタイムラインで使われていないキャラ(立ち絵・声)は含めない。キャラ設定の立ち絵フォルダ配下のファイルは個別ファイルとして扱わず、そのキャラの「立ち絵」1 件にまとめる。
- データ保存先:プラグインの DLL と同じフォルダの JSON(例 `credit-data.json`)。YMM4 の `user\setting` はバージョンごとのフォルダなので使わない。

## 実装者に任せるもの

- プロジェクト構成、MVVM の組み方、ウィンドウのレイアウト詳細。
- ymmp の探索方法(再帰探索か、型ごとの読み取りか)。素材の取りこぼしがないことを優先。
- 声質の表示名の作り方(YMM4 内部の名前解決を使うか、`API / Arg` のままにするか)。
- 保存データの JSON スキーマ。保存は書き込み失敗時に元データを壊さない方式で行う。
- テストの範囲(ymmp 解析と出力組み立ては UI から切り離してテスト可能にするのが望ましい)。
